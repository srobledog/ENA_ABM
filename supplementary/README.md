# Supplementary material

This directory contains Appendices S1–S7 in Markdown and PDF, together with their machine-readable tables and verification evidence.

1. S1: ODD model description.
2. S2: preregistered experimental design.
3. S3: parameter and configuration dictionary.
4. S4: additional results and machine-readable tables.
5. S5: exploratory sensitivity analysis.
6. S6: verification and reproducibility evidence.
7. S7: computational environment and complete reproduction workflow.

The Markdown files are intended for transparent inspection and version control; the PDFs are submission-ready companion documents.
