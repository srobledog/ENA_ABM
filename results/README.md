# Results

This directory contains compact, manuscript-facing evidence from reproduction run 1 and the verification comparison with run 2.

- `summaries/`: profile registry, threshold estimates, bootstrap intervals, fixed-cost comparison, robustness summaries, sensitivity summaries, and the main report.
- `figures/`: four final scientific figures from v0.5.
- `verification/`: stopping diagnostics, manifests, SHA-256 inventories, automated-test record, and the byte-level reproduction comparison.

The large paired-run files are available in the `v0.5.0` Release packages and are not stored in Git history.
